## Project Overview

Prime Pele | Mobile Waxing is a website project created
for a mobile beauty business based in Cape Town,
South Africa.

The website provides information about mobile waxing
services and allows visitors to view services, browse
the gallery, read testimonials, check frequently asked
questions and make appointment enquiries.

## Website Objectives

- Provide information about Prime Pele services.
- Improve the business's online presence.
- Display services and pricing information.
- Allow customers to make appointment enquiries.
- Provide contact information.
- Create a professional and responsive website.

## Target Audience

The website is designed for:

- University students
- Working professionals
- Busy parents
- Women aged 18–45
- Cape Town residents
- Customers seeking convenient home-based beauty services

## Part 1 — Website Planning and Structure

Part 1 focused on planning and creating the initial
structure of the Prime Pele website.

The website was organised into multiple HTML pages
with navigation links connecting the main sections.

The content introduces the business, describes its
services and provides information for potential clients.

## Part 2 — CSS Styling and Responsive Design

Part 2 focused on improving the website's appearance,
layout and responsiveness.

### CSS Improvements

- Created a shared external stylesheet.
- Implemented a CSS reset.
- Defined reusable colour variables using `:root`.
- Styled the navigation bar and hero sections.
- Created reusable button styles.
- Used CSS Grid for service cards and contact layouts.
- Added hover effects and transitions.
- Applied consistent typography and spacing.

### Responsive Design

The website includes media queries at:

- 768px for tablets and smaller screens.
- 480px for small mobile devices.

These breakpoints adjust navigation, typography,
spacing, service cards and contact layouts.

## Part 2 Lecturer Feedback and Corrections

The lecturer identified several areas for improvement.

### Corrections Applied

### Testing
