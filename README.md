# Prime Pele | Mobile Waxing

## Project Overview

Prime Pele | Mobile Waxing is a website project created for a mobile beauty business based in Cape Town, South Africa.

The website provides information about mobile waxing services and allows users to find service information, view the gallery, read testimonials, check frequently asked questions and make appointment enquiries.

## Website Objectives

- Provide information about Prime Pele services
- Improve the organisation's online presence
- Display services and pricing information
- Allow customers to make appointment enquiries
- Provide contact information
- Create a professional and responsive website

## Target Audience

The website is designed for:

- University students
- Working professionals
- Busy parents
- Women aged 18–45
- Cape Town residents
- Customers looking for convenient home-based beauty services

## Website Pages

The website contains the following pages:

- Home
- About
- Services
- Gallery
- Testimonials
- FAQ
- Contact
- Privacy Policy
